Menü Yönetim Paneli

Ürünleri, fiyatları, fotoğrafları ve alerjenleri buradan düzenleyin. Yayınla'ya bastığınızda değişiklikler yaklaşık 1 dakika içinde QR menüde görünür.

Erişim anahtarını nasıl alırım?
  1. GitHub → Fine-grained token oluştur sayfasını açın.
  2. Token name: “QUU Menü Admin”, Expiration: istediğiniz süre.
  3. Repository access: “Only select repositories” → quu-menu.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Generate token'a basın, çıkan anahtarı kopyalayıp yukarıya yapıştırın.

Anahtar yalnızca bu cihazın tarayıcısında saklanır, hiçbir yere gönderilmez (sadece GitHub'a).
